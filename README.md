# Кусур

**[kusur.online](https://kusur.online)** — каде е најевтина **целата кошничка** во Велес. Внесуваш што купуваш, а апликацијата ти кажува во која продавница е најевтино, дали вреди втора продавница, што поевтинело од последниот пат и дали акцијата е вистинска.

Цените се од маркетите, секој ден. Без сметки и без следење: кошничката и следените производи остануваат во твојот прелистувач.

## Од каде се цените

Од 18 април 2025 големите синџири се законски обврзани секој ден до 10 часот да ги објават продажните цени на своите веб-страници (измени на Законот за заштита на потрошувачите, Службен весник од 4 март 2025). Кусур ги чита тие јавни ценовници секое утро, со искрен User-Agent и пауза меѓу барањата.

| Синџир | Продавници во Велес | Извор |
|---|---|---|
| Жито | Центар, Ване, Општина | `zito.proverkanaceni.mk` |
| Стокомак | Велес, Велес 2 | `stokomak.proverkanaceni.mk` |
| Рамстор | Велес | `ramstore.com.mk/marketi/` |
| КАМ | 8-ми Септември, 11-ти Октомври, Бауман | PDF ценовници од `kam.com.mk` |

## Како работи

- **Препознавање на производите:** 171 тип производ („млеко", „бело сирење", „прашок за перење"…) со рачно прегледани мапи — категорија на маркетот → тип (`data/category-map.json`) и, за КАМ што нема категории, производ → тип (`data/product-map.json`).
- **Кошничка:** најевтиното купување на потребната количина од секој тип во секоја продавница; најдобар план со најмногу две продавници. Клуб-цените (само со картичка) не се сметаат за поевтино.
- **Историја:** се чуваат само дневните промени (365 дена); од нив — „поевтинето од последната посета" и „вистинска акција?" (споредба со најниската цена во 30-те дена пред акцијата).
- **Апликацијата** е статичка (Next.js): секое утро GitHub Actions ги презема цените, прави мал пакет со цени (`public/data/`) и ја објавува. Сите пресметки ги прави телефонот.

Детали: `SPEC.md` и `SPEC-*.md` по модул.

## Развој

Потребен е Node.js 22.18 или понов (TypeScript се извршува директно).

```
npm install
npm run fetch                 # денешните ценовници во data/ (~50 мин; Жито е бавен)
npm run basket -- "млеко, 10 јајца, сирење, кафе и прашок за перење"
npm run drops -- --since 2026-10-01 "кафе, ориз"
npm run build-data            # пакетот за телефонот
npm run dev                   # апликацијата на http://localhost:3000
npm test && npm run typecheck
```

Одржување на мапите: `npm run categories` (нови категории, непрегледани производи на КАМ) и `npm run propose` (предлози за КАМ, за рачен преглед).
