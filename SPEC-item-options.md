# Spec: item-options (колку точно е ставката)

Нов модул. Зависи од: `product-matching` (типови, кандидати), `basket`, `price-history`. Го менува: `web-app` (Кошничка, Пребарај), пакетот со цени (`src/publish/`).

## Цел

Денес секоја ставка е „најевтиното од типот": за „прашок за перење" апликацијата зема кој било бренд и која било грамажа, па „Жито 189 ден." наспроти „КАМ 259 ден." значи Гросе Ваше 3 кг наспроти Дуел 2,7 кг — не иста работа. Корисникот треба да може да каже **колку точно**:

1. **Кој било** (како денес) — најевтино од типот за потребната количина.
2. **Бренд** — „Персил", „Nescafé": во секоја продавница најевтиниот од тој бренд за потребната количина.
3. **Ист производ** — ист бренд **и иста грамажа** (Nescafé Classic 200 г): се споредува истото пакување во секоја продавница.

Кога избраното го нема во продавница: **замена**, јасно означена зошто („Нема Nescafé во Стокомак — инстант кафе Одор"), наместо тивко друг производ.

Одлуки (2026-10-02, корисник): „нескафе" во список значи бренд Nescafé (македонски говор: „нескафе" е и инстант и фрапе, но кога се бара — брендот); ако брендот го нема → замена со образложение; „ист производ" = ист бренд + иста грамажа; млекото по масленост — **не** во оваа верзија; сирење, јогурт, кисело млеко — масленоста не е важна.

## Факти (снимки 2026-10-02)

- **Nescafé:** речиси исти производи насекаде — Classic 200 г 435 ден. (Жито лименка, КАМ, Рамстор; Жито стакло 419), Gold 75 г 239 ден. (Жито, КАМ, Стокомак; Рамстор 285). Стокомак: само Gold 75 г и лименка 250 г.
- **Персил прашок:** различни пакувања по синџир — Жито 1,5 / 5 / 7 / 9 кг, КАМ 2,25 / 7,5 кг, Рамстор 1,35 / 1,5 / 2,7 / 3 кг; Стокомак нема прашок (само гел, капсули, дискови). → „бренд" е корисен; „ист производ" ретко има пар.
- Брендот е речиси секогаш во името („ПРАШОК ПЕРСИЛ 5кг", „ПЕРСИЛ ДЕТЕРГЕНТ РЕГУЛАР 3КГ", „ДЕТЕРГЕНТ РЕГУЛАР ПЕРСИЛ 2.25КГ"), понекогаш само во описот (КАМ) или на латиница. Грамажата ја читаме веќе (`parseQuantity`).
- Синџирите имаат и сопствени марки (5КА, Камко, Кузина, Р…): тие се бренд како секој друг.

## Однесување

### Брендови
- Нов фајл `data/brands.json`: бренд → име за приказ, шаблони (кирилица и латиница, на пр. `ПЕРСИЛ|PERSIL`), и за кои типови важи (Персил: прашок, течен детергент, капсули). Рачно прегледан, како мапите.
- `npm run brands -- <тип>`: најчести „први зборови" кај кандидатите на типот што не се препознаени како бренд — за дополнување на фајлот (човек одлучува).
- Брендот на кандидатот се одредува при `build-data` (име + опис) и оди во пакетот (`b`), за телефонот да не носи шаблони.
- **Брендови како збор во списокот:** „нескафе" → тип „инстант кафе" со бренд Nescafé; „персил" → „прашок за перење" со бренд Персил. Алијасите се во `data/brands.json`. Општите зборови остануваат општи („инстант кафе", „прашок").

### Ниво на ставката
Ставката во кошничката добива ниво: `any` (стандардно) | `brand` (+ бренд) | `exact` (+ бренд + грамажа).
- **`brand`:** кандидатите се ограничуваат на брендот; ако ги нема во продавницата → `any` со ознака „замена: нема <бренд>".
- **`exact`:** кандидатите се ограничуваат на брендот и пакување со иста грамажа (±3%); купувањето е во тие пакувања. Ако ги нема → `brand` (друга грамажа) со ознака; ако нема ни бренд → `any` со ознака.
- Секое купување носи `match: "exact" | "brand" | "any"` и, кај замена, причина. Споредбата на кошничката ги рангира продавниците по сума како досега; на секоја продавница се гледа бројот на замени („1 замена"), а во деталите — која и зошто.
- `price-history` / Поевтинето: следените типови остануваат по тип (без бренд) во оваа верзија.

### Свинско месо по делови
- „Свинско месо" како еден тип се дели на делови: **бут, плешка, кременадли/каре, вешалица, ребра** (+ постојното „мелено"). „Свинско месо" во списокот го прашува корисникот кој дел (нема погодување). Правилата по име (`require`) по дел, од вистинските имиња во ценовниците.

### Апликација
- **Кошничка:** панелот на ставката добива „Колку точно?": *Кој било* / *Бренд* (листа на брендовите што постојат за типот во Велес, со најниска цена) / *Ист производ* (по избор од Пребарај). Резултатот: значка „замена" по продавница и образложение во деталите.
- **Пребарај:** кај производ — „Додај токму овој производ" (ниво `exact`) и „Додај го брендот" (`brand`).
- Брендот и нивото се чуваат со ставката во прелистувачот.

## Надвор од оваа верзија
- Масленост кај млекото (одлука на корисникот).
- Варијанти „регулар / колор / сензитив" кај ист бренд (сега се ист бренд).
- Следење на бренд во Поевтинето.

## Критериуми за успех

1. Тест: „нескафе" → инстант кафе, бренд Nescafé; во продавница без Nescafé → замена со ознака и причина.
2. Тест (вистински пакет): „Nescafé Classic 200 г" (`exact`) → Жито 419 (стакло) / КАМ 435 / Рамстор 435; Стокомак → замена (бренд Nescafé, друга грамажа) со ознака.
3. Тест: „персил" (`brand`) → во Стокомак замена (нема Персил прашок), во другите најевтиниот Персил за 3 кг.
4. `data/brands.json`: брендови за најмалку 15 типа каде брендот е важен (кафе, инстант кафе, прашок, течен детергент, омекнувач, паста за заби, шампон, пелени, пиво, газиран сок, чоколадо, …); структурни тестови (шаблоните не се преклопуваат меѓу брендови на ист тип).
5. Свинско месо: 5 дела со производи во најмалку 3 синџири; „свинско месо" во списокот бара избор.
6. Пакетот со бренд: ≤ 2 MB необработено (сега 1,54 MB).
7. Апликацијата: изборот „Колку точно?" и значката „замена" работат на телефон.
8. `npm test`, `npm run typecheck`, `npm run build` поминуваат.

## Тестирање
- Чисти функции (ограничување по бренд/грамажа, замена, причина) — синтетички кандидати; вистинскиот пакет за критериумите 2–3.
- `data/brands.json` — структурни тестови како мапите.
- UI рачно на телефон.

## Граници (додатно на `SPEC.md`)
- **Секогаш:** замената е видлива (никогаш тивко друг бренд кога е избран бренд).
- **Прво прашај:** нови алијаси-брендови во списокот (што значи кој збор); промена на делењето на месото.
- **Никогаш:** погодување на брендот од цена или од продавница.

## Отворено

- Делови на свинското месо: дали листата е точна (бут, плешка, кременадли/каре, вешалица, ребра)?
