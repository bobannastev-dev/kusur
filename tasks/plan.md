# План: product-matching

Spec: `SPEC-product-matching.md` (одобрен 2026-10-02). Задачите: `tasks/todo.md`. Претходен модул: `tasks/price-ingest/`.

## Преглед

Сите 9 продавници да учествуваат во споредбата: 148 нови категории на Жито се прегледуваат, КАМ (без категории) добива прегледана мапа производ → тип, клуб-цените на Рамстор не ја искривуваат споредбата, и се поправа читањето „16рол 3/1". Секоја задача остава `npm test` и `npm run typecheck` зелени.

## Архитектонски одлуки

- **Мали поправки прво, рачната работа потоа.** Задачите 1–3 се код со тестови (вид на акција, клуб-цена, количина); 4 и 7 се рачен преглед на податоци, кој е најголем и најмалку ризичен технички.
- **Вид на акција како сиров текст.** `Offer.promoKind` е текстот од изворот, без толкување; толкувањето („ЛОЈАЛНОСТ" = клуб-цена) е на едно место (`comparisonPrice`), за да се смени лесно ако се појави нов вид.
- **Мапа производ → тип е паралелна на мапата категорија → тип.** Ист формат (еден ред по клуч, `[]` = свесно исклучено, без клуч = непрегледано), ист вид структурни тестови. `matchesType` го бира изворот по синџир: ако синџирот има мапа на производи, неа; инаку категориите. Нема мешање на двете за ист синџир.
- **Предлозите се посебен фајл, не мапата.** `npm run propose` пишува `data/review/КАМ-proposals.json`; во `data/product-map.json` влегува само прегледано. Така грешка во правилата не стигнува до корисникот.
- **Клучни зборови по тип** (`keywords` во каталогот) служат само за предлози кај синџири без категории. За Жито/Стокомак/Рамстор однесувањето не се менува.
- **Без нови зависности.**

## Граф на зависности

```
1 promoKind ── 2 comparisonPrice (клуб-цена)
3 „16рол 3/1"
4 преглед 148 категории на Жито
5 product-map (инфраструктура) ── 6 keywords + npm run propose ── 7 преглед КАМ ── 8 проверка на покриеност и кошничка
```

1–4 се независни меѓусебно; 5–8 се низа.

## Задачи (детали во `tasks/todo.md`)

### Фаза 1: Цени и количини
1. `promoKind` во `Offer` и во трите парсери
2. `comparisonPrice` и клуб-цена во споредбата
3. Количина „16рол 3/1"

### Фаза 2: Жито
4. Преглед на 148 нови категории на Жито

**Checkpoint A:** тестови зелени; `npm run categories` — 0 нови категории за Жито/Стокомак/Рамстор; кошничка со клуб-цена покажува забелешка; преглед со човек.

### Фаза 3: КАМ
5. Мапа производ → тип: фајл, вчитување, `matchesType`, структурни тестови, непрегледани во `npm run categories`
6. Клучни зборови по тип и `npm run propose`
7. Преглед на предлозите за КАМ → `data/product-map.json`
8. Проверка: основни типови во КАМ, примерна кошничка во сите 9 продавници

**Checkpoint B (модулот готов):** сите 8 критериуми од spec-от; `/review`; Second Brain.
